# Rollout: composite invoice ids

Referenced by [ADR-0009](../adrs/0009-single-store-idempotency-gate.md). Present
so the example corpus has no broken links — `adr-lens` reports one, and an
example should be clean.

1. Ship `buildInvoiceId` behind a flag, writing both id forms.
2. Backfill the mapping from hashed to composite ids.
3. Flip reads to the composite id.
4. Drop the hashed column after one billing cycle.
